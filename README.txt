Ghost Aura Free - نسخة أولية مستقلة

المحتويات:
- index.html: واجهة التطبيق وأدوات الحساسية وDPI.
- manifest.webmanifest و sw.js: دعم التثبيت كتطبيق ويب (PWA) عند استضافته عبر HTTPS.

مهم:
هذه ليست APK. بيئة الإنشاء الحالية لا تحتوي على Android SDK أو Gradle أو أدوات Android اللازمة لإنتاج ملف APK وتوقيعه. يمكن فتح المشروع في Android Studio بعد تغليفه كتطبيق Android (WebView/Capacitor) أو استضافته HTTPS وتثبيته كتطبيق ويب.
التطبيق لا يعدّل ملفات Free Fire ولا يتصل بها. قيم الحساسية ملفات مرجعية تحفظ محلياً فقط.
